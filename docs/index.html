Twitch Emote Presets

Userscript для Twitch Creator Dashboard, который позволяет сохранять и быстро переключать наборы эмоута по слотам.

How to use

Как пользоваться

  1. Установи расширение для userscript'ов, например Tampermonkey, и нажми Install userscript выше.
  2. Открой Twitch Creator Dashboard и перейди на страницу: /u/USER/viewer-rewards/emotes. Панель появляется только на странице управления эмоута.
  3. При первом запуске прочитай AI Disclosure. До согласия скрипт не отправляет запросы в Twitch.
  4. Нажми New preset, задай имя и выбери эмоута для нужных слотов. Клик по слоту открывает picker.
  5. Чтобы сохранить текущую раскладку Twitch как основу для нового пресета, используй Copy current.
  6. Эмоута внутри одной категории можно переставлять drag-and-drop. Жёлтая рамка предупреждает, если эмоута придётся перенести из другой категории.
  7. Сохрани пресет и нажми Apply, когда захочешь применить его. Во время выполнения в верхней части панели показывается текущий статус и кнопка Stop.
Важно: скрипт использует внутренние Twitch GQL-запросы. Twitch может изменить их без предупреждения, поэтому после обновлений сайта отдельные функции иногда могут потребовать обновления userscript'а.

Что умеет

Presets Сохраняет наборы эмоута и раскладку по слотам.
Snapshot mode Может восстанавливать точное состояние, включая пустые слоты.
Emote picker Поиск по библиотеке с превью статических и анимированных эмоута.
Automatic updates Если установлен через этот файл, userscript manager может получать новые версии автоматически.
